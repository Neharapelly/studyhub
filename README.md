# StudyHub – Low-Fidelity Wireframe

## 📚 Project Overview

StudyHub is an online learning platform designed to help students access courses, lessons, quizzes, and track their learning progress.

This project was created as a **Low-Fidelity Wireframing & Design** project for CodeAlpha Task 1.

The design focuses on simple layouts, clear navigation, content structure, and user flow without using colors or detailed visual styling.

## 🎯 Task

**CodeAlpha – Task 1: Wireframing & Low-Fidelity Design**

## ✨ Features

* Home / Landing Page
* Login Page
* Student Dashboard
* Course Details
* Lesson / Learning Page
* Quiz Page
* Progress Tracking Page
* Simple navigation between screens
* Black-and-white low-fidelity wireframe design
* Responsive layout for different screen sizes

## 🎨 Design Approach

The project uses a **low-fidelity wireframe approach**.

* Black and white layout
* Simple typography
* Placeholder areas for images and icons
* Basic buttons and navigation
* Clear content hierarchy
* Simple user flow
* No high-fidelity colors or visual effects
