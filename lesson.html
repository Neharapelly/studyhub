What is Flexbox?

Flexbox is a CSS layout system that helps you arrange elements easily in rows or columns.

It is especially useful when creating responsive websites that work on different screen sizes.

Important Concepts

  • Flex Container
  • Flex Items
  • Justify Content
  • Align Items
